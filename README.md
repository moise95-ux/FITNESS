# TLcoachfit V9

Application fitness mobile-first en français, prête pour GitHub Pages.

## Vidéos
- Les démonstrations ne contiennent plus d'animation de coach.
- Les exercices de musculation utilisent les clips réels YMove disponibles gratuitement pour usage commercial.
- Les exercices cardio (tapis, marche, vélo, rameur, burpees/HIIT et mountain climbers) utilisent des vidéos réelles de personnes provenant de Pexels.
- Les vidéos sont chargées depuis leurs sources externes pour éviter de distribuer les fichiers vidéo eux-mêmes.

Sources :
- YMove : https://ymove.app/free-exercise-videos
- Pexels : https://www.pexels.com/

## Fonctionnalités
- Programmes musculation, perte de graisse, cardio, HIIT et personnalisé
- Calendrier avec 5 jours d'entraînement + 2 jours de repos
- Séances guidées et historique
- Vidéos réelles par exercice
- Chronomètre d'exercice
- Chronomètre cardio avec durée, distance, vitesse et calories estimées
- IMC et profil
- Statistiques et progression
- Logo TLcoachfit

## Déploiement
Décompresser le ZIP puis envoyer le contenu du dossier sur GitHub. Pour GitHub Pages, choisir la branche contenant `index.html` comme source.
